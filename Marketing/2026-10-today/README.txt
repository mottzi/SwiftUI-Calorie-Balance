Count.kcal: Now to midnight

Finished iPhone hero, 15 October 2026.

Open index.html to view the animation. The 3840 x 2160 PNG is the static hero.
The matching MP4 is a ten-second, 30 fps loop: Now, Midnight, Now.
The native forward animation plays at half speed and then in reverse, with
pauses at each endpoint. The final Now state matches the opening Now state.
The web preview repeats indefinitely using the video element's loop attribute.
The SVG contains editable type and embedded device images and can be opened
in Affinity. The copy uses the installed Avenir Next typeface.

Included alternatives:
- Light and dark screen-only MP4 loops, 1206 x 2622.
- Original-resolution Now and Midnight screenshots in both appearances.
- Transparent device PNGs, 1350 x 2760, for light Now and dark Midnight.
- A 1920-pixel WebP poster for smaller web placements.

Device frames:
Original Apple iPhone 18 Pro, Silver and Black, from Apple Design Resources.
https://developer.apple.com/design/resources/#product-bezels
https://devimages-cdn.apple.com/design/resources/download/Bezel-iPhone-18.dmg
Screen placement in each original 1350 x 2760 frame: x 72, y 69,
width 1206, height 2622. Hardware remains stationary and unmodified.
https://developer.apple.com/app-store/marketing/guidelines/#section-products

The app ran in Debug sample-data mode on iOS 27. No personal health data is
shown. The app's Now timestamp is 8:09 AM; the status bar matches it.
Midnight holds recorded intake and projects resting energy. It is an estimate.
