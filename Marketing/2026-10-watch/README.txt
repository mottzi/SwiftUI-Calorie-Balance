Motion
The recorded native SwiftUI Now-to-Midnight transition plays at half speed,
then plays in reverse to return to Now. Both endpoints have a pause.
The opening and closing states match for continuous looping.
The preview uses muted, loop and playsinline. Reduced-motion preferences
pause automatic playback. MP4 players need repeat enabled for indefinite play.

Source and fidelity
The existing Watch calorie views and toggleMode animation were rendered by
an isolated simulator capture build. A capture-only task triggered the same
mode changes that the ring button triggers. No production app source changed.

The fixed demo snapshot has 257 active calories, 1231 recorded resting
calories, 1730 projected resting calories, and 1660 calories eaten.
Now shows a 172 kcal surplus. Midnight shows an estimated 327 kcal deficit.
The estimate holds intake constant and adds 499 projected resting calories.
No personal health data was used. A light background is a marketing canvas;
the Watch app retains its native dark interface in both versions.
