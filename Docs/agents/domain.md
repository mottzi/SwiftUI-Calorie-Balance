# Domain docs

Use one root `CONTEXT.md` and `Docs/adr/` for this single-context repository.

Before exploring, read `CONTEXT.md`, or a root `CONTEXT-MAP.md` if one later exists, and relevant ADRs under `Docs/adr/`. Proceed silently when these files are absent. Create domain documents lazily when terms or decisions are resolved.

Use glossary terms consistently. Flag contradictions with existing ADRs rather than overriding them silently.
