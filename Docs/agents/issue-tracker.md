# Issue tracker: local Markdown

Issues live as one Markdown file each under `.scratch/<feature>/issues/`. Calorie-card sharing uses `.scratch/calorie-card-sharing/issues/`.

Number tickets from `01` in dependency order, with a short slug in the filename. Each ticket has What to build, Blocked by, Status, and acceptance criteria. Blocking edges list local ticket numbers and titles. Work any ticket whose blockers are complete. Use ready-for-agent for approved work and completed only after verification and the requested review.

Read and update the local file when a skill says to fetch or publish a ticket. Do not publish new GitHub issues for this work. GitHub copies #1–#8 were superseded by this local tracker at the user's explicit request.
